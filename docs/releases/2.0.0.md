# SUDARI 2.0.0 🦦🐚

A little river otter, in your language.

- Redrawn original pixel art: small ears, a flatter head, creamy muzzle, expressive eyes and a long tapered tail. The shell-opening animation now sits upright with the shell between the paws.
- Rebuilt Pomodoro shell artwork with complete edges, legible focus/break labels and matching size/click targets. It sits close to the head and clears the current animation when needed.
- Illustrated right-click menu, icons, live preview and tabbed settings.
- 12 languages across dialogue, menus, the timer and settings, including Arabic RTL. English-first Windows installer and a language picker on first launch for macOS/portable Windows. The selected language persists and can be changed in Settings.
- Validated settings, screen-aware sizing, transparent-pixel hit testing and protection against stale sprite loads.
- Windows x64, macOS Intel and macOS Apple Silicon builds, with six downloadable artifacts and SHA-256 checksums.

## Downloads

- **Windows:** `Sudari-2.0.0-Setup.exe` or `Sudari-2.0.0-Portable.exe`.
- **Mac M series:** `Sudari-2.0.0-mac-arm64.dmg` (ZIP also available).
- **Mac Intel:** `Sudari-2.0.0-mac-x64.dmg` (ZIP also available).

Windows 10/11 x64; macOS 12+. No Node.js or Python required. Builds are unsigned and not Apple-notarized. macOS keyboard/scroll reactions require Accessibility permission; other features remain available without it.
