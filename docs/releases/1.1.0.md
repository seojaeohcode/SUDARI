### Installation & verification

Windows builds are unsigned; Mac builds are not Apple-notarized. Follow the first-launch instructions in the [README](https://github.com/seojaeohcode/SUDARI#-수다리-입양하기). macOS keyboard/scroll reactions require Accessibility / Input Monitoring permission and an app restart. CI checks do not replace manual testing of macOS permissions, every OS version, multi-monitor hardware or fullscreen Spaces.

`SHA256SUMS.txt` contains checksums for all six downloads. Existing settings are retained. No account or subscription is required.
