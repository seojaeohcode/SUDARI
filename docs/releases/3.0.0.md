# SUDARI 3.0.0 🦦🍎

## Mac installation repair

- The published v2.0.1 Apple Silicon app failed strict signature verification: `code has no resources but signature indicates they must be present`. The complete bundle is now ad-hoc signed with the required Electron entitlements.
- CI verifies DMG integrity, strict recursive signatures after copying from DMG and extracting ZIP, the executable CPU, and launches both actual packaged apps on Intel and Apple Silicon.
- Each Mac job now builds only its requested CPU, so the published file is the one checked by its matching runner.
- **These builds are not Developer ID-signed or Apple-notarized. Gatekeeper still rejects them by default.** If blocked, follow the app-specific exception instructions after downloading from this repository: [Mac installation](https://github.com/seojaeohcode/SUDARI/blob/main/docs/mac-install.md) · [Mac 설치 안내](https://github.com/seojaeohcode/SUDARI/blob/main/docs/mac-install.ko.md).

## Dragging recovery on Windows and Mac

- End dragging when mouse capture is lost, the button is released outside the canvas, the window loses focus, or the right-click menu opens.
- Recover a missed release when pointer movement shows the left button is no longer pressed.
- Added native Electron input tests across 17 poses, sizes 2–5, repeated dragging, typing/scroll IPC events during dragging, right-click menu actions, settings, idle/sleep and capture-loss cases. These complement the existing layout, language, timer and first-launch checks.
