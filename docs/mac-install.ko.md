# 🍎 Mac에서 수다리 설치하기

**M 시리즈 Mac은 `Sudari-3.0.0-mac-arm64.dmg`, Intel Mac은 `Sudari-3.0.0-mac-x64.dmg`를 받으세요.** [공식 다운로드](https://github.com/seojaeohcode/SUDARI/releases/latest)

1. 수다리가 실행 중이면 메뉴바의 수다리 아이콘에서 **종료**하세요.
2. DMG를 열고 **Sudari**를 **Applications(응용 프로그램)** 폴더에 끌어 놓으세요. 이전 앱이 있으면 새 앱으로 교체하세요.
3. 응용 프로그램 폴더에서 **Sudari**를 실행하세요. 개인 설정은 앱과 별도로 저장되어 앱을 교체해도 유지돼요.

## “손상되었기 때문에 열 수 없습니다”가 나오나요?

v2.0.1 Mac 배포본에서 앱 전체의 서명 검증이 실패하는 문제를 확인했어요. **먼저 v3.0.0 이상으로 교체해 주세요.** v3부터 앱 전체에 무결성 확인용 임시 서명(ad-hoc)을 적용하고, DMG·ZIP에 담긴 앱의 서명을 검증해요.

다만 **Apple Developer ID 서명·공증은 없는 배포본**이에요. 파일 무결성 검사를 통과해도 macOS가 기본 실행을 막을 수 있어요. 공증은 Apple이 배포자를 확인하고 앱을 검사하는 별도 절차이며, 임시 서명이 이를 대신하지는 않아요.

직접 이 저장소에서 내려받은 앱을 실행하려는 경우, 먼저 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 확인하세요. 앱 실행을 한 번 시도한 뒤 표시될 수 있어요. [Apple의 안내](https://support.apple.com/en-gb/102445)

### “그래도 열기”가 없거나 계속 막힐 때

**아래 작업은 이 저장소에서 직접 받은 v3.0.0 이상을 신뢰하는 경우에만 진행하세요.** `SHA256SUMS.txt`와 다운로드 파일의 체크섬을 대조할 수도 있어요. M 시리즈 DMG라면 터미널에서 다음 명령으로 확인해요.

```bash
shasum -a 256 "$HOME/Downloads/Sudari-3.0.0-mac-arm64.dmg"
```

앱을 응용 프로그램 폴더에 복사한 뒤 **터미널**에 아래 명령을 붙여 넣으세요.

```bash
codesign --verify --deep --strict "/Applications/Sudari.app" && \
xattr -dr com.apple.quarantine "/Applications/Sudari.app" && \
open "/Applications/Sudari.app"
```

앱의 서명 검증에 성공한 경우에만 **Sudari.app의 다운로드 격리 표시**를 제거하고 실행해요. Mac 전체의 Gatekeeper 설정이나 다른 앱은 바꾸지 않아요. 이것은 수다리를 신뢰한다는 사용자의 예외 선택이며, Apple 공증을 추가하는 작업은 아니에요.

서명 검증 오류가 나오면 이후 명령은 실행되지 않아요. 앱을 다시 받고, 받은 파일 이름·macOS 버전·오류 문구를 [이슈](https://github.com/seojaeohcode/SUDARI/issues)로 알려 주세요. 회사·학교에서 관리하는 Mac은 관리자 정책에 따라 예외가 제한될 수 있어요.

## ⌨️ 키보드·스크롤 반응

메뉴바의 수다리 → **키보드·스크롤 반응 켜기**를 선택하고, 시스템 설정에서 **손쉬운 사용 / 입력 모니터링** 권한을 허용한 뒤 다시 실행하세요. **드래그·우클릭·타이머는 이 권한 없이 사용할 수 있어요.**

## 검수 범위

Mac Intel·Apple Silicon에서 DMG 검사, DMG에서 복사한 앱 및 ZIP에서 푼 앱의 엄격한 서명 검사, 실제 패키지 실행을 검사해요. 별도로 드래그·우클릭 메뉴·타이핑/스크롤 이벤트·17개 동작·2~5배 크기의 입력 검사를 수행해요. 자동화된 타이핑·스크롤 검사는 입력 후크가 보내는 IPC 이벤트를 사용하며, 개인 Mac의 접근성 권한 허용 여부까지 대신 검증하지는 않아요.

CI에서 생성한 로컬 파일의 실행 검사는 인터넷 다운로드 후 Gatekeeper의 허용을 의미하지 않아요. **현재 배포본은 공증되지 않아 Gatekeeper의 기본 신뢰 검사를 통과하지 않습니다.**
